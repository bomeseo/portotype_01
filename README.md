# 라이브 경매 프로토타입

중고·한정판 상품을 둘러보고 입찰부터 거래 후기까지 체험하는 반응형 웹 프로토타입입니다.
기존의 초록색 브랜드와 순수 HTML/CSS/JavaScript 구조를 유지했습니다.

## 사이트 바로가기

[라이브 경매 프로토타입 열기](https://live-auction-prototype-park-0906.pokesheugu.chatgpt.site/)

링크로 방문 가능한 공개 프로토타입입니다. GitHub 저장소의 접근 권한은 별도로 관리합니다.
공개 사이트가 내려주는 HTML/CSS/JavaScript는 브라우저에서 확인할 수 있으며, 비공개 저장소는 Git 기록과 저장소 접근을 제한합니다.

## 실행

프로젝트 폴더에서:

```sh
npm install
npm run dev
```

주소: http://127.0.0.1:8080

빌드 도구 없이 `index.html`을 직접 열 수도 있지만, 브라우저 저장소 동작을 일관되게 확인하려면 로컬 서버를 권장합니다.
Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd run dev`를 사용하세요.

## 체험 순서

1. 첫 방문의 **라이브 경매 시작하기**에서 닉네임 → 관심 카테고리 → 거래 지역·방식 → 알림·공개 범위를 설정합니다. 관심사·맞춤 추천·이벤트 알림은 선택 사항이며 기본 공개 범위는 비공개입니다.
2. 가입 중 또는 **내 정보 → 전화번호 인증**에서 테스트 번호 `01012345678`을 입력합니다.
3. **데모 인증번호 받기**를 누르고 `123456`으로 인증합니다. 실제 문자는 발송하지 않습니다.
4. 홈의 **처음 거래 따라하기**에서 실제 찜·채팅·입찰·거래·후기 버튼을 따라 누를 수 있습니다. 홈에서 상품을 검색하거나 관심 상품을 담고 입찰합니다.
5. 내가 최고 입찰자인 상품 하단의 **데모: 지금 마감하고 낙찰 흐름 보기**로 마감을 체험할 수 있습니다.
6. **내 정보 → 거래 내역**에서 약속 저장·상대 확인, 송금 표시, 판매자 입금 확인, 전달·배송, 수령 확인, 후기 작성을 진행합니다.
7. **문의**로 채팅을 열고 **데모 답장 받기**로 응답을 체험합니다.
8. 등록 화면에서 직접 사진을 올리거나 예시 사진을 사용합니다. 내 판매 상품은 입찰 전 수정·삭제할 수 있습니다.

처음부터 제공되는 예시 거래로도 거래 완료·후기를 체험할 수 있습니다.
차단 번호 예시 `01000000000`은 인증이 거절됩니다.
상단 **체험 안내**에서 이 브라우저의 데이터를 초기화할 수 있습니다.

## 파일 구조

```text
index.html                  화면 컨테이너와 파일 로드 순서
app/
  seed.js                   데모 회원·상품·대화·거래 데이터
  store.js                  저장, 권한, 입찰, 마감, 상품·대화 처리
  helpers.js                문자열 이스케이프, 금액·시간, 방해금지 계산
  icons.js                  공용 UI 아이콘
  ui.js                     대화상자·확인창·상품 카드
  router.js                 화면 전환, 내비게이션, 뒤로가기
  main.js                   앱 초기화, 마감 타이머, 알림 배지
  features/
    membership.js           가입 정보 검증, v3 → v4 데이터 보완, 거래 진입 조건
    journey.js              거래 약속·역할별 단계·문제 접수·취소 처리
    tutorial.js             실제 행동을 감지하는 6단계 따라하기
    assistant.js            상품·거래별 안내, 질문·설명 초안, 예산 계산
    listing.js              상품 초안 복원·자동 저장·등록 전 확인
    discovery.js            가입 진입, 최근 본 상품·검색, 마감 알림·공유
    account.js              데모 번호 인증, 가입 설정 진입, 방해금지
    bidding.js              입찰 금액 입력과 확정
    safety.js               신고·차단·차단 해제
    trades.js               거래 단계와 후기 작성
  views/
    onboarding.js           4단계 가입·설정 화면, 중단 후 이어하기
    trade.js                거래 약속·입금·전달·수령·문제 처리 화면
    home.js                 검색·카테고리·인기순·취향 탐색
    likes.js                관심 상품 모아보기
    create.js               사진 업로드, 등록·수정
    detail.js               상품 상세·갤러리·비공개 입찰 내역
    profile.js              내 판매·입찰·거래와 설정 진입
    seller.js               판매자 신뢰 정보·공개 내역·후기
    chat.js                 상품별 대화, 계좌 전달, 데모 답장
    support.js              FAQ·문의·알림·FAQ 도우미
styles/
  tokens.css                브랜드, 기본 타이포, 전체 레이아웃
  components.css            버튼·폼·카드 공통 도구·대화상자
  marketplace.css           홈·경매 상세·등록
  account-chat.css          계정·판매자·채팅·고객센터
  flows.css                 가입·튜토리얼·거래 진행 화면의 반응형 구조
scripts/
  serve.cjs                 로컬 정적 서버
  build.cjs                 JS 구문·참조 검증 및 공개 파일 빌드
tests/
  domain.test.cjs            저장·입찰·권한·마감·차단·알림·거래 상태 테스트
  screens.test.cjs           가입·초안·튜토리얼·거래·후기 DOM 통합 테스트
```

`js/data.js`는 기존 상품 예시의 원본으로 사용합니다.
그 외 기존 `js/`, `css/`, `legacy/` 파일은 이전 구현 참고용으로 보존했으며 현재 진입점에서는 로드하지 않습니다.
새 기능은 `app/`와 `styles/`에 추가하세요. 도메인 변경은 `store.js`, 화면 표현은 해당 view에서 관리합니다.

## 구현 범위

- 검색, 대·소 카테고리, 거래 방식 필터, 인기 TOP100, 관심사 기반 목록
- 관심 상품 저장 및 진행·마감 필터
- 데모 전화번호 인증, 제한 번호 확인, 인증번호 만료·횟수 제한
- 상품 등록·수정·삭제, 최대 5장 사진 압축 저장
- 입찰 단위·금액·회원·차단 검증, 경매 마감·유찰·낙찰
- 입찰자 이름 미표시 및 내 입찰 구분
- 판매자 프로필, 예시 신뢰 정보, 선택적 거래 내역 공개
- 거래 단계, 완료 거래의 중복 방지 후기
- 상품별 채팅, 계좌 전달, 신고·차단, 데모 상대 답장
- 관심사·선호 지역·방식·접속 공개·방해금지 설정
- 알림함, 고객센터 FAQ·문의·신고 상태·데모 답변
- 쿠팡·11번가 일반 검색 연결, 상황별 거래 도우미
- 가입 절차와 관심사 추천 동의, 방해금지·알림별 설정
- 상품 초안 자동 저장·복원, 하자·구성품·배송비와 등록 전 확인
- 구매자·판매자 역할 체험, 약속 확인과 역할별 거래 단계
- 취소·노쇼·문제 접수 후 진행 보류와 명시적인 데모 검토
- 실제 버튼을 따라 누르는 초보자 튜토리얼, 최근 검색·최근 본 상품
- 입찰 최종 금액·배송비 확인 및 과도한 금액 재확인 안내
- 새로고침 후 localStorage 복원

## 프로토타입 경계

모든 데이터는 **현재 브라우저의 localStorage**에 저장됩니다. 다른 사용자·기기와 공유되지 않습니다.
실제 개인정보나 금융정보는 입력하지 마세요. 저장 공간이 부족하면 안내하며, 저장되지 않은 변경은 새로고침 시 사라질 수 있습니다.

실제 로그인, SMS·본인 인증, 외부 사기 조회, 영구 제재 집행, 실시간 다중 사용자 채팅·동시 입찰, 푸시 알림, 결제·에스크로, AI API는 연결되지 않았습니다.
경쟁 입찰을 몰래 생성하지 않습니다. 상대 답장·거래 진행·문의 답변은 명시적인 데모 버튼으로 체험합니다.
판매자의 평점·접속 정보·초기 후기는 예시이며 화면에 데모로 구분합니다.

쿠팡 링크는 일반 검색 링크입니다. 파트너스 계정과 발급된 제휴 링크가 없으므로 수익 추적을 하지 않습니다.
외부 신품 가격과 중고 상품 가격을 실시간으로 비교하지 않습니다.
도우미는 현재 상품·거래 단계에 맞춘 규칙과 문구 템플릿을 사용합니다. 질문은 채팅 입력란에 초안으로만 넣고 사용자가 직접 전송합니다. 실제 생성형 AI나 사기 판정은 수행하지 않습니다.

기존 v3 브라우저 데이터는 보존하여 v4 필드를 보완하며, 기존 방문자도 새 가입 절차를 완료할 수 있습니다. 상품별 공유 링크는 고정 예시 상품(1~5)에 한해 다른 방문자에게 열립니다. 새로 등록한 상품은 서버가 없는 데모이므로 다른 브라우저와 공유되지 않습니다.

디자인 수정은 `styles/`와 `app/views/`를 중심으로 진행하고 `app/features/`의 거래 규칙과 튜토리얼 대상 ID는 유지하세요. `flows.css`는 가입·거래 화면의 구조를 담당하며 브랜드 토큰과 분리되어 있습니다.

## 검증

```sh
npm test
npm run build
```

브라우저 UI 검사와 별개로 도메인 동작 및 DOM 기반 화면 흐름 테스트를 실행합니다.
배포 파일은 `dist/`에 생성됩니다. 서버 코드나 테스트 파일은 공개 빌드에 포함하지 않습니다.
